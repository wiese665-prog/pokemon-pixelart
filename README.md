# Pokémon Pixelarchiv

Deutsche Sprite-Galerie für Pokémon Smaragd, Rubin, Saphir, Feuerrot, Blattgrün, HeartGold und SoulSilver.

## Starten

Repository herunterladen und `index.html` im Browser öffnen. Internetzugang ist für Bilder erforderlich. Kein Build und keine Installation nötig.

## Erste Version

- 24 ausgewählte Pokémon mit deutschen Namen (21 in Generation III, 24 in Generation IV)
- Sieben Editionsfilter, Suche nach Name und Nationaldex-Nummer
- Front-, Rück- und Shiny-Ansichten sowie 2×-/3×-Zoom
- Responsive Darstellung und sichtbare Fehlermeldungen bei nicht verfügbaren Bildern

Die Editionsauswahl bezeichnet den Grafikstil, nicht die Fangbarkeit im jeweiligen Spiel. Die Auswahl ist kein vollständiger Pokédex.

## Quellen und Zuordnung

Die Grafiken werden direkt aus [PokéAPI/sprites](https://github.com/PokeAPI/sprites) geladen. Deutsche Namen und Oberfläche sind lokal hinterlegt. Es werden keine ROMs oder Sprachversionen der Spiele heruntergeladen.

| Edition | Sprite-Verzeichnis bei PokéAPI |
| --- | --- |
| Smaragd | generation-iii/emerald |
| Rubin, Saphir | generation-iii/ruby-sapphire |
| Feuerrot, Blattgrün | generation-iii/firered-leafgreen |
| HeartGold, SoulSilver | generation-iv/heartgold-soulsilver |

PokéAPI fasst die jeweiligen Editionspaare zusammen. Diese Quelle ist kein Nachweis für eine besondere deutsche Grafikfassung. Externe Verfügbarkeit der Bilder kann sich ändern.

## Dateien

- `index.html`: Oberfläche
- `style.css`: Gestaltung
- `app.js`: deutsche Namen, Editionszuordnung und Galerie
